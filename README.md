# C# Switch Calculator

İki tam sayı üzerinde toplama, çıkarma, çarpma ve bölme yapan konsol hesap makinesi. Sıfıra bölme kontrolü ve tekrar işlem seçeneği içerir.

## Çalıştırma

.NET 10 SDK ile depo klasöründe:

```bash
dotnet run
```

İki sayıyı girip işlem menüsünden 1–5 arasında seçim yapın. 5 programdan çıkar.

## Öğrenilen konular

- `switch` ile menü seçimi
- Aritmetik işlemler
- `if` koşulu ve döngüyle tekrar
